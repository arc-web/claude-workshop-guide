# Post-Event Checklist

## Immediate (same day)
- [ ] Update hub README with final project names, descriptions, and live links
- [ ] Commit any presentation files to hub repo
- [ ] Revoke all PAT tokens (GitHub Settings > Developer Settings > Tokens)
- [ ] Verify all pod repos have notes.md filled in

## Within 24 hours
- [ ] Share repo links and live app URLs with all attendees via Discord/email
- [ ] Share NotebookLM audio overviews if teams generated them
- [ ] Post event photos/screenshots to Discord #general
- [ ] Send feedback survey

## Within 1 week
- [ ] Archive pod repos (or leave open if teams want to continue)
- [ ] Write facilitator retrospective: what worked, what broke, what to change
- [ ] Update this guide with lessons learned
- [ ] Back up any ephemeral content (Discord messages, temporary files)
