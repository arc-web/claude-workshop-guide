# Pre-Event Checklist (2-4 weeks before)

## Attendee Research
- [ ] Registration data collected (name, email, role, AI experience, computer type)
- [ ] Attendee profiles researched in batches of 7-10
- [ ] Room Expertise Map built (skill tiers across attendees)
- [ ] Flags actioned (email typos, missing info, follow-ups)

## Pod Assignment
- [ ] Pods formed (3-4 people each, mix of experience levels)
- [ ] Each pod has a leader identified
- [ ] Each pod has at least one Claude subscriber
- [ ] Pod rationale documented (why this grouping)

## Infrastructure
- [ ] GitHub org ready
- [ ] Hub repo created with all guides and templates
- [ ] Pod repos created (only for confirmed attendees - not speculative)
- [ ] CLAUDE.md customized per pod (members, roles, levels)
- [ ] Fine-grained PAT tokens created (one per pod repo, contents:write only)
- [ ] PAT tokens NOT committed to any repo
- [ ] Hub README has pod table with links to all pod repos

## Discord
- [ ] Server created with channels: #general, one per pod, #facilitators
- [ ] API keys pinned in each pod channel
- [ ] PAT tokens pinned in each pod channel
- [ ] Quick-start instructions pinned in #general

## Presentations
- [ ] Workshop intro HTML customized for your event
- [ ] Collab guide HTML reviewed and updated
- [ ] Both tested in browser (arrow key navigation works)

## Communications
- [ ] Pre-event email sent with: Discord invite, setup guide link, what to bring
- [ ] Reminder 24 hours before
